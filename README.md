# Enow | Portfolio

A responsive, one-page portfolio website built with HTML, CSS, and JavaScript. It presents my background, selected course projects, skills, gallery, and contact information.

## Live Site

[View the portfolio](https://enowadan.github.io/Portfolio/).

## Features

- Responsive layouts for desktop and mobile
- Project highlights for the Simple Recipes page, About section, Contact form, and Bootstrap footer
- Accessible image lightbox with captions, previous/next navigation, keyboard controls, and close behavior
- Semantic page structure and responsive CSS

## Technologies

- HTML5
- CSS3
- JavaScript
- Bootstrap coursework

## Run Locally

Open `index.html` in a browser. The site uses externally hosted Unsplash images and Google Fonts.
